# SmartKeyPrompts

根据玩家当前情境显示按键提示，让操作更直观，减少查找按键设置的时间。

## 主要功能

- 根据手持物品、交互目标等情境显示对应操作提示。
- 提示文字跟随玩家实际按键绑定，支持自定义按键说明。
- 默认按住 **K** 配合左键打开当前提示的按键设置，右键切换 HUD 位置，滚轮调整缩放。
- 支持数据驱动提示规则，以及 JEI、EMI 等模组的相关提示。
- 支持 `/skp guide` 按键引导，可用于任务或剧情中的操作教学。

## 支持版本

- NeoForge 1.21.1
- Fabric 1.21.1 / 1.20.1
- Forge 1.20.1

需要安装对应版本的 **OELib 0.3.0**。Fabric 1.20.1 版本需要 **Java 21**。
