# 提示显示顺序与布局锚点

## 指定显示顺序

`KeyPrompt.withOrder(int)` 指定提示的显示顺序，按数值升序排列：

```java
PromptUtils.addDesc("帮助")
        .forKey("key.keyboard.h")
        .withCustom(true)
        .withOrder(100)
        .toGroup("example");
```

默认值为 `0`，相同数值保持提交顺序。较小值显示在前，较大值显示在后，
可用于将帮助、页面切换等常驻提示放在普通操作提示之后。支持负数。

排序只作用于绘制快照，不修改公共提交列表，也不改变提示的身份、去重规则或
默认／准星分区。复用同一提示对象时，可以修改其顺序；排序在缓存 hash 计算
之前进行，显示顺序发生变化时会刷新快照。

## 缩放后的布局锚点

原来的底部和中部定位按每行 `14` 像素估算总高度，但实际绘制行距为
`16 * scale`。当提示数量变化时，底部位置会漂移；中部布局也会偏离中心。

布局现在统一使用实际缩放行距。底部每行先计算其距离列表末尾的行数，再计算
到屏幕底边的偏移并取整。这样最后两行的位置只取决于缩放和窗口高度，不会
随其他提示出现或消失而改变，也避免分开取整造成的 1 像素跳动。

中部布局同步使用缩放后的高度；顶部与准星布局保持原有坐标计算。
原先使用错误高度的底部／中部布局会一次性移到修正位置。

## 回归检查

```text
./gradlew verifyPromptOrder verifyPromptLayout
```

这两个检查也接入了 `check`。它们无需启动游戏，直接验证实际 HUD 快照和
行坐标计算，包括同序稳定性、动态顺序、去重身份、底部两行位置、不同提示
数量、不同窗口高度、小数缩放，以及顶部／中部／准星布局。
